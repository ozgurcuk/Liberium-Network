# Liberium Network

Liberium is an EVM-compatible blockchain under development. Its planned launch
uses Proof of Authority (PoA) and the native currency LIB.

| Parameter | Pre-launch value |
| --- | --- |
| Network name | Liberium |
| Native currency | Liberium (LIB) |
| Currency decimals | 18 |
| Proposed mainnet Chain ID | 767366 (0xbb586) |
| CAIP-2 identifier | eip155:767366 |
| Status | Incubating; mainnet not launched |
| Public RPC endpoints | Not yet available |
| Public explorer | Not yet available |

This page publishes network metadata only. It is not a mainnet launch
announcement, a security certification, or a claim that the proposed Chain ID
has already been accepted by the public chain registry.

The development network and its local test allocations are not the mainnet.
Final genesis, operational endpoints and signed production packages will be
announced separately after validation. No private keys, wallets, administrator
addresses, local-network endpoints or private source code are published here.
